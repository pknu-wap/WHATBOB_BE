## 1. 확정된 핵심 아키텍처 결정 요약 (`T04-D01` ~ `T04-D02`)

| 결정 ID | 주제 | 사용자 확정 선택 | 핵심 설계 계약 |
| :--- | :--- | :--- | :--- |
| **T04-D01** | 복수 선택 투표 DB 저장 구조 | **2번 확정 (참여자 행에 투표용지 배열 내장 `Embedded Ballot Array`)** | 별도의 `room_round_votes` 테이블을 늘리지 않고, `room_round_members` 행에 참여자가 선택한 후보 번호 목록(`voted_candidate_ids: JSON Array`)과 투표 제출 시각(`voted_at`)을 저장한다. 저장 전 서버 코드에서 현재 라운드의 유효 후보 여부·중복 제거·오름차순 정규화를 검증한다. 동일 제출 재전송(`멱등성`) 비교와 향후 재투표(`T06`) 시 투표 칸 초기화(`NULL`)를 단일 테이블에서 빠르게 처리한다. |

## 2. 확정된 상세 처리 흐름 및 잠금 규칙

1. **투표 제출 요청 검증 및 멱등성(`Idempotency`) (`T04-D01`)**:
   - 대상 `Room` 및 현재 활성 `RoomRound` 행을 잠그고(`with_for_update()`), 현재 라운드 상태가 `VOTING`인지, 그리고 요청의 투표 회차(`vote_round_no`, 전달된 경우)가 현재 회차와 일치하는지 확인한다(이전 라운드·이전 회차의 지연 요청은 거절).
   - 현재 라운드의 활성 참여자(`room_round_members`)인지 검증한다.
   - 제출된 후보 ID 목록(`candidate_ids`)을 검증한다:
     - 빈 선택(`[]`)은 거절한다(최소 1개 이상 ~ 전체 후보 선택 가능, 본인 제안 후보 선택 가능).
     - 같은 후보 ID가 중복 전달된 경우(예: `[1, 1]`) 거절하거나 유효성 오류로 처리하여 한 사람이 같은 후보에 2표를 주지 못하게 한다.
     - 모든 후보 ID가 현재 라운드의 살아있는 `room_round_candidates`에 속하는지 확인한다(존재하지 않는 후보나 다른 라운드 후보는 거절).
     - 비교 일관성을 위해 후보 ID 리스트를 오름차순 정렬된 배열로 정규화한다.
   - **이미 투표를 제출한 참여자(`voted_at IS NOT NULL`)인 경우**:
     - 정규화된 후보 ID 배열이 기존 `voted_candidate_ids`와 정확히 일치하면 **동일 제출 재전송**으로 판단하여 상태를 바꾸지 않고 기존 성공 응답을 그대로 반환한다.
     - 다른 후보 조합으로 변경하려 한 경우에는 투표 수정 불가 오류로 거절한다.
2. **투표 진행 중 비공개 원칙**:
   - 아직 미제출 참여자가 남아 있는 경우:
     - REST 응답 및 WebSocket 알림에는 **투표 제출 완료 인원(`voted_count / total_member_count`)과 본인의 제출 여부**만 포함하며, 중간 득표수나 누가 어떤 메뉴에 투표했는지는 절대 노출하지 않는다.
     - `rooms.state_version` 증가 및 Outbox 알림 저장 후 `commit`한다.
3. **전원 투표 완료 시 개표 박제 및 공동 1위 확정 (`T04-D02`)**:
   - 현재 라운드의 활성 참여자 전원이 투표를 완료한 순간:
     - 활성 참여자 전원의 `voted_candidate_ids`에 포함된 각 후보 ID를 1표씩 합산한다.
     - 후보 중 최다 득표수(`max_votes`)를 구하고, 각 `room_round_candidates` 행에 `final_vote_count`와 `is_winner = (count == max_votes and max_votes > 0)`를 기록(`UPDATE`)한다.
     - 최다 득표 동점 후보가 여러 개이면 임의 추첨이나 결선 투표 없이 **해당 후보 전체를 공동 1위(`is_winner = True`)**로 확정한다.
     - 라운드 상태를 `RESULT`로 전환하고, `rooms.state_version` 증가 및 Outbox 알림(후보별 최종 득표수와 공동 1위 목록 포함, 개인별 누가 무엇을 찍었는지는 결과에서도 비공개) 저장 후 상위 트랜잭션을 `commit`한다.
