# T02~T09 설계 마무리·내일 구현 인계 계획

최신 사용자 지시: 2026-11-13 대화에서 2시간 이내 완료할 대상은 아키텍처 설계다. 구현과 실제 검증은 내일(2026-11-14) 진행한다. 기존 T01 서버 구현과 격리 검증은 유지하며, 오늘 T02~T09의 실행 코드를 추가하지 않는다.

최신 정리: 주요 정책 선택과 통합 설계·T09 계획 작성을 마쳤다. [최종 설계 기준과 구현 확인 항목](39-design-baseline.md)을 다음 작업의 시작점으로 사용한다. 사용자 선택·기술 초안·실제 데이터/환경 검증을 구분한다.

## 현재 상태

- T01: 백엔드 구현·격리 검증 기록이 있다. 실제 브라우저·운영 적용과 남은 운영 설계는 별개다.
- T02: [주요 선택 10항목](39-t02-architecture-checklist.md)을 모두 선택했다. 선택 결과는 `1A,2A,3A,4A,5B,6A,7A,8B,9B,10A`다. 데이터·API·학습·실패·경합의 [통합 기술 초안](39-implementation-architecture.md)을 작성했다. M1A·M2A·M3A·M4A도 선택했다.
- T03~T08: [기존 작업 명세](39-uuid-user-tickets.md)와 ADR의 제품 정책을 바탕으로 상태 전이·DB/API·실패/경합 처리의 [통합 초안](39-implementation-architecture.md)을 작성했다. 기술 초안 전체의 승인·구현을 뜻하지 않는다.
- T09: 마이그레이션 보존·전체 전환 시나리오·회귀·MySQL 경합·브라우저·1GB 환경의 [검증·인계 계획](39-validation-and-handoff.md)을 작성했다. 실제 테스트 실행 결과는 내일 구현 후 기록한다.

큰 정책·사용자 행동·데이터 보존을 바꾸는 미결정은 체크리스트로 함께 제시하고 선택·보류를 받는다. 이미 선택한 사항을 다시 질문하지 않으며 모든 컬럼·함수·검증 사례를 별도 선택으로 늘리지 않는다. 기술 세부 초안과 사용자 승인 정책을 구분한다.

[M1~M4](39-final-design-choices.md)는 사용자가 M1A·M2A·M3A·M4A를 선택해 모두 결정했다. 개인 보정 최대 ±5점·90일 반감기·제한 추첨, 8재료군, 별도 기존 환경 학습, 사진 1,200만 픽셀 상한·긴 변 512px 정규화를 따른다. 그 외 표/경로/상태/운영 수치는 통합 문서의 기술 초안으로 묶어서 검토한다. 실제 데이터 대응·모델 품질·자원 검증을 설계 완료와 혼동하지 않는다.

[T03~T08 체크리스트](39-cross-feature-architecture-checklist.md)의 R1~R5 선택을 모두 마쳤다. 사용자 선택은 R1A 단일 API 프로세스·R2A 두 단계 전환·R3A 원본 사용자 행 물리 삭제·R4A 탭 알림과 인증 재확인·R5A 주소를 알면 조회 가능한 사진 URL이다. R5B 서명 URL·R5C 조회자별 권한 검사 제안은 채택하지 않았다. 기술 계약·T09 검증 계획도 통합 문서에 작성했다.

사용자가 운영 환경을 RAM 1GB·백엔드/MySQL 동시 실행으로 확인하고 R1A를 선택했다. 실제 메모리·동시 연결 용량과 학습 실행 자원은 측정 전 확정하지 않는다. 사진 UI는 본인 화면·방 참여자 표시만 제공하고 클릭·확대·공유 기능은 제공하지 않는다. R5A의 사진 조회에는 별도 인증·서명 만료를 적용하지 않으며 업로드·교체·삭제의 본인 인증은 유지한다.

## 내일의 구현 순서

1. 오늘의 설계·미결정·API/DB 계약과 실제 코드 기준선을 확인한다.
2. T02 개인 기능·학습 모델 기반, T03 방, T04~T05 프로필을 구분해 구현·관련 검증한다. 병렬 작업 시 파일 소유권과 공용 스키마를 먼저 맞춘다.
3. T02·T03을 바탕으로 T06 이관, T04~T06을 바탕으로 T07 병합, 이후 T08 왕복 전환을 구현한다.
4. T09 전체 흐름·기존 데이터·MySQL 경합·회귀를 실제 실행하고 문서·LOG를 결과에 맞춘다. 운영 배포·프론트 전체 화면 구현·실제 피드백으로 확인한 품질은 별도 범위다.

## 일정 정정에 따른 작업 정리

- 시간 제한을 구현까지로 잘못 해석해 시작한 병렬 구현은 중단했다. 두 작업 에이전트 모두 파일 수정·테스트 실행이 없었다.
- 루트 에이전트가 추가한 User 메타데이터 필드 4개, Pillow·scikit-learn 의존성 2줄, `.data/` ignore 1줄만 제거했다. 기존 T01 변경과 사용자 변경을 되돌리지 않았다. DB 변경·패키지 설치는 수행하지 않았다.
- 이 문서는 일정과 설계 산출물의 기준이다. 설계 초안을 구현 완료나 테스트 통과로 기록하지 않는다.
