## 설계 문서 해석

- 각 최종 설계와 구체 승인 기록이 이전 티켓 초안의 설계 대기 문구보다 우선한다.
- D20은 그룹 제출에서 임시 추가 제외 입력을 받지 않고 시작 때 고정한 전원 프로필 제외 조건만 사용하기로 결정됐다. T03의 해당 차단은 해제됐다.
- T01N D07은 상세 기록의 2번·3일이다. 종료 시 원문을 제거하고 요약만 원래 종료 시각부터 3일 보관한다. 최종 요약의 잘못된 선택 번호를 정정했으며 정책은 바꾸지 않았다.
- T01N D10의 성공 HTTP 응답에도 전체 공통 상태·버전을 반환하는 계약을 지킨다. D11의 접속 표시와 구분한다.
- T03의 동일 제출 재전송은 현재 라운드와 본인 권한을 확인한 뒤 기존 결과를 반환한다. 마지막 제출로 VOTING·RESULT에 진입했다는 이유로 동일 재전송을 거절하거나 다시 추천하지 않는다. 취소·이전 라운드 요청은 여전히 거절한다.
- T04 투표 API·복수 후보 결과 확정, T05~T06 퇴장 후 방장 결정·재투표, D19 재경기는 구현하지 않는다. T03 자체의 단일 후보 무투표 결과는 구현 범위다.
