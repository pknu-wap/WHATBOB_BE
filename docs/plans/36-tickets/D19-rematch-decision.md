# D19: 결과 이후 같은 방에서 다시 고르기 결정

## Parent

[개발 명세 #43](https://github.com/pknu-wap/WHATBOB_BE/issues/43), 원본 요청 #36, 사용자 보류 항목 Q19.

## What to build

코드 구현이 아닌 사용자 결정 대기 항목이다. 결과 이후 같은 방에서 다시 고르기를 제공할지와 결과·참여자 보존 및 새 라운드 전환 범위를 사용자 결정에 따라 기록한다. 현재는 사용자 요청에 따라 보류한다.

## Acceptance criteria

- [ ] 사용자의 명시적 결정 전까지 결과 이후 다시 고르기 지원·미지원 어느 쪽도 확정하지 않는다.
- [ ] 지원을 선택했다면 시작 권한·대기실 전환·새 참여자 수용·최신 조건 고정·이전 결과 보존·새 라운드 식별 계약을 정리한다.
- [ ] 미지원 또는 후속 범위로 분리하기로 선택했다면 결과 이후 화면과 재이용 경로의 확정 범위를 기록한다.
- [ ] 결정 내용만 명세에 반영하고 필요한 구현 티켓은 결정 이후 추가한다. 아직 정해지지 않은 기능을 기존 티켓에 포함하지 않는다.
- [ ] 사용자가 보류 중인 동안 같은 질문을 자동 반복하거나 전체 기능이 모두 확정됐다고 보고하지 않는다.

## Blocked by

None (사용자 결정 대기이며 자동 착수 대상이 아님).

## Draft status

보류 유지. 분할안 승인 후에도 결정 대기 라벨을 사용하고 `ready-for-agent`로 표시하지 않는다. 결과 이전의 확정된 구현 티켓을 불필요하게 차단하지 않는다.
