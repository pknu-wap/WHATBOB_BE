# T04: 복수 선택 투표부터 공동 1위 결과까지

## Parent

[개발 명세 #43](https://github.com/pknu-wap/WHATBOB_BE/issues/43), 원본 요청 #36.

## What to build

참여자가 후보 메뉴를 복수 선택해 투표하고 전원 제출 시 메뉴별 득표수와 공동 1위를 확인할 수 있게 한다. 투표 중에는 제출 인원만 보이고 다른 사람의 개별 선택은 공개하지 않는다.

## Acceptance criteria

- [ ] 현재 라운드·투표 회차 참여자만 후보 중 최소 하나부터 전체 후보까지 선택할 수 있고 자기 후보도 선택 가능하다.
- [ ] 존재하지 않는 후보·다른 라운드 후보·빈 선택·같은 후보 중복 선택으로 유효 표가 늘지 않는다.
- [ ] 제출 후 수정은 거절하고 동일 제출 재전송은 같은 결과로 복원한다. 이전 라운드·회차의 지연 요청은 현재 투표를 변경하지 않는다.
- [ ] 전원 제출 시 한 번만 결과를 확정하며 각 선택에 한 표씩 반영한다.
- [ ] 최다 득표 메뉴 전체를 공동 1위로 반환한다. 동률 임의 추첨·추가 투표는 없다.
- [ ] 투표 중 REST·WebSocket에는 제출 인원만 공개하고 중간 득표수와 개인별 선택은 노출하지 않는다.
- [ ] 결과에서 메뉴별 득표수와 최다 득표 메뉴를 조회하되 개인별 투표는 공개하지 않는다.
- [ ] 별도 단계 제한 시간·강제 마감은 추가하지 않는다. 방 만료·방장 종료 정책을 유지한다.
- [ ] 필요한 투표·결과 저장, 마이그레이션, 프론트 상태 계약과 실제 인증 요청·알림 검증을 함께 제공한다.
- [ ] 결과 이후 다시 고르기나 결과의 개인 식사·평가 자동 저장을 임의로 추가하지 않는다. Q19는 보류 상태로 남긴다.
