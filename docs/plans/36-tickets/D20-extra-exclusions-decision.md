# D20: 주문서 추가 제외 조건의 지원·적용 방식 결정

## Parent

[개발 명세 #43](https://github.com/pknu-wap/WHATBOB_BE/issues/43), 원본 요청 #36, 사용자 보류 항목 Q20.

## What to build

코드 구현이 아닌 사용자 결정 대기 항목이다. 저장된 설정 외에 주문서 요청으로 전달하는 이번 추천만의 추가 제외 조건을 같이 고르기에서도 지원할지, 지원한다면 누구에게 언제 적용할지 결정 내용을 기록한다. 현재는 사용자 요청에 따라 보류한다.

## Acceptance criteria

- [ ] 사용자에게서 명시적인 결정을 받은 경우에만 지원·미지원과 적용 범위를 기록한다. 스킬 추천·미응답·보류를 승인이나 거절로 간주하지 않는다.
- [ ] 지원을 선택했다면 요청 계약, 전원 조건 합산 여부, 조건 확정 시점과 추천 생성 순서가 시작 시 저장된 설정 고정 정책과 일치하도록 정리한다.
- [ ] 미지원을 선택했다면 관련 입력의 처리와 프론트 안내를 명시적으로 정리한다.
- [ ] 어느 선택이든 명세와 T03의 수용 기준·검증 기대값에 반영한 후 차단을 해제한다.
- [ ] 사용자가 보류 중인 동안 동일한 질문을 자동으로 반복하거나 구현 에이전트가 정책을 대신 정하지 않는다.

## Blocked by
