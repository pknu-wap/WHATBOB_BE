# #52 첫 번째 티켓 · 웹에서 카카오 계정 연결과 왓밥 로그아웃

[상위 명세 #52](https://github.com/pknu-wap/WHATBOB_BE/issues/52)를 기준으로 설계 결정을 기록한다.

## 사용자 흐름

1. 웹에서 쿠키를 받아 처음 방문이면 UUID 사용자를 만들고, 재방문이면 기존 사용자를 복원한다.
2. 현재 UUID 세션에서 카카오 계정 연결을 시작한다. 카카오 인증 결과를 받으면 준비 단계에서 세션과 연결 대상을 확인하고, 확정 단계에서 기록 이관과 새 세션 발급을 함께 처리한다.
3. 왓밥 로그아웃을 확정하면 현재 웹 세션을 폐기하고 새 UUID 세션을 발급한다. 기존 카카오 계정의 기록은 그 계정에 남는다. 확정 응답이 유실되면 기존 전환의 결과를 확인하고 복구한다.

## Q1 · 인증 요청 주소 확정

2026-11-18 사용자 결정으로 웹 브라우저는 현재 보고 있는 왓밥 웹 주소의 인증 API로 요청을 보낸다. Vercel이 뒤에서 요청을 기존 백엔드로 전달하고, 응답의 인증 쿠키를 웹 브라우저에 전달한다. 웹 주소와 백엔드 호스트를 따로 운영하던 구성에서, 이 티켓의 웹 인증 트래픽은 같은 웹 주소를 경유하는 방식으로 바꾼다. [이전 배포 관계 결정](39-t01-auth-architecture.md#웹-배포-관계와-쿠키-전달), [Vercel의 외부 API 요청 전달](https://vercel.com/docs/routing/rewrites#external-origin-rewrites)

- 브라우저가 사이트 간 인증 쿠키를 차단하면 새 UUID 생성이나 기존 UUID 복원에 실패할 수 있다. 같은 웹 주소를 사용하면 이 제약을 피할 수 있지만 중간 전달 설정과 장애 처리, 통합 검증이 필요하다. 공통 도메인 아래 웹과 API를 배치하는 대안에는 도메인·HTTPS 설정 등 운영 변경이 필요하다. [WebKit의 사이트 간 쿠키 정책](https://webkit.org/blog/10218/full-third-party-cookie-blocking-and-more/)
- 현재 Vercel 전달 코드는 요청의 인증 쿠키와 응답의 `Set-Cookie`를 전달하지 않는다. 구현 시 세션에 필요한 쿠키와 보안 검사에 필요한 요청 정보가 양쪽으로 전달되고, 인증 응답이 공유 캐시에 저장되지 않는지 검증한다. 기존 왓밥 세션과 계정 전환의 서버 검사를 적용한다. [현재 Vercel API 전달 코드](https://github.com/pknu-wap/WHATBOB_FE/blob/21c3436b172e6c2d14449fc2b914e81f140cb548/app/api/proxy.js), [UUID 인증 API](../UUID_AUTH_API.md)
- 기존 API 주소에 발급된 쿠키는 웹 주소에 자동으로 넘어오지 않는다. 운영 웹에서 기존 UUID 복원 쿠키를 실제로 사용하는지와 전환 시 필요한 대응은 배포 전에 확인한다. 실제 브라우저에서 최초 생성, 새로고침 복원, 카카오 연결, 로그아웃 및 응답 유실 복구를 검증한다.

## Q2 · 카카오 복귀(`redirect_uri`) 수신 주체 확정 (`T03-D01`)

2026-11-18 사용자 결정(**선택지 1번**)으로 카카오 인증 직후 돌아오는 `redirect_uri`는 **왓밥 웹 콜백 화면**이 먼저 수신한다.

- 웹 콜백 페이지가 열리면 즉시 로딩 화면을 표시하고 `window.history.replaceState`로 주소창의 `?code=...&state=...` 쿼리를 제거해 새로고침 중복 소비를 방지한다.
- 웹 화면은 동일 출처 프록시를 통해 백엔드 `POST /api/auth/transitions`(`action: "KAKAO_LINK"`, `code`, `state`)를 호출하고, 반환된 `TransitionPrepareResponse`(대상 카카오 계정의 `표시 닉네임`, 서버에서 마스킹한 이메일 `masked_email`)로 같은 화면에서 연결 대상 확인 모달/화면을 표시한다.
- 로그아웃 후 재연결(`requires_reauth=true`) 시 카카오톡 인앱 브라우저가 감지되면, 카카오 인가 요청 전에 외부 브라우저(Safari·Chrome) 열기 또는 현재 카카오톡 계정으로 계속하기 안내를 먼저 표시한다.
