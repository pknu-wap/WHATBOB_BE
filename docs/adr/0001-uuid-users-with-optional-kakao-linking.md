# UUID 기본 이용과 선택적 카카오 계정 연결

첫 방문에 UUID 사용자와 중복 없는 랜덤 표시 닉네임을 자동 생성하고, 개인 기능과 같이 고르기 모두 로그인 없이 동일한 사용자로 이용한다. 카카오 로그인은 이용 조건 대신 기록을 이어 쓰기 위한 선택적 계정 연결로 유지하여, 로그인 없이 시작할 수 있는 흐름과 계정 기반 기록 연결을 함께 제공한다.

카카오 계정을 연결하면 UUID 사용자의 기록을 카카오 계정으로 이관하고 해당 UUID는 폐기한다. 같은 카카오 계정으로 이관되는 여러 UUID의 데이터는 모두 합치며, 어느 한 UUID 사용자를 대표로 남기는 방식은 사용하지 않는다.

UUID 기본 이용 도입 이전부터 있던 카카오 계정에 로그인하는 경우에는 기존 계정의 프로필과 기록을 보존하고 UUID의 기록을 그 계정으로 합친다. 별도의 카카오 계정을 새로 생성하지 않는다.

방에 참여 중인 사용자는 로그인·로그아웃을 할 수 없다. 재접속 유예와 다른 기기의 참여에 따른 제한은 [방 재접속과 계정 전환](0002-room-reconnect-and-account-switching.md)을 따른다.

이관할 닉네임과 프로필 사진은 통합 대상 중 가장 먼저 생성된 UUID 사용자의 값을 유지하고, 이후 사용자가 수정할 수 있다. 이미 카카오 계정에서 직접 수정한 프로필은 나중에 더 오래된 UUID의 기록을 이관하더라도 유지한다. 카카오에서 받은 닉네임과 사진으로 자동 교체하지 않는다. 알레르기·섭취 불가·비선호 목록은 양쪽 항목을 모두 보존해 합친다.

카카오 로그아웃 후에는 새 UUID 사용자와 랜덤 닉네임으로 시작한다. 카카오 계정의 기존 기록은 보존하며, 이후 다시 로그인하면 새 UUID의 기록도 같은 계정으로 이관한다.
