# 마지막 실제 인기 순위를 DB에 보관

요즘 인기 메뉴는 집계 대상인 전날 하루 동안 식사를 기록한 사용자가 5명 이상일 때 실제 순위를 보여준다. 인원이 기준 아래로 내려가면 마지막으로 표시한 실제 순위를 유지해야 하므로, 그 순위 한 벌을 MySQL에 보관한다. 메모리에만 보관하면 서버를 재시작했을 때 이전 순위를 잃고, 현재 기록으로 과거 순위를 다시 계산하면 기록 삭제나 집계 기간 이동의 영향을 받는다.

매일 한국시간 자정에 전날 하루치 기록을 집계하고 유효한 새 순위를 한 번에 반영한다. 서버가 자정을 놓쳤다면 재시작할 때 가장 최근에 놓친 집계만 보충한다. 사용자 수 기준을 충족하지 못하면 기존 순위를 유지하고, 실제 순위가 처음부터 없을 때는 #54 댓글의 초기 목록을 제공한다. 홈 인기 메뉴 API는 저장된 결과를 조회한다. 집계와 표시 기준은 [홈 메뉴 설계](../plans/54-menu-photo-design.md)를 따른다.
