# 방 재접속 유예와 계정 전환 제한

2026-11-13 변경: 사용자 결정에 따라 재접속 유예를 60초로 정했다. 이전 30초 설계를 대체하며 유예 후 일반 참여자 퇴장·방장 종료 정책은 유지한다.

사용자의 방 연결이 끊기면 60초 동안 기존 참여 상태를 유지하고, 유예 안에 재접속하면 그대로 복귀한다. 유예가 끝나도 돌아오지 않으면 일반 참여자는 자동 퇴장시키고 방장은 방을 종료한다. 기존 일반 참여자를 오프라인 상태로 계속 남겨두는 동작을 이 정책으로 대체한다.

방 참여 중에는 로그인·로그아웃을 모두 제한한다. 로그인하려는 카카오 계정이 다른 기기에서 방에 참여 중인 경우에도 로그인을 제한하여, 방 참여가 끝나기 전에 계정 전환이나 UUID 기록 이관이 발생하지 않도록 한다.

2026-11-13 보충 합의: 방 참여 요청을 시작한 순간부터 응답 대기 중에도 로그인·로그아웃·계정 전환을 차단한다. 참여 성공 시 기존 방 참여·60초 재접속 유예 제한으로 이어지고, 참여 실패가 확정되면 요청 중 차단을 해제한다. 응답 유실·시간 초과는 실패 확정으로 취급하지 않으며, 서버에서 참여 여부와 요청 처리 결과를 확인한 뒤 해제 여부를 판단한다. 처리 중인 참여 요청이 뒤늦게 성공할 수 있는 상태를 미참여 확정으로 오인하지 않는다.

프론트에서 전환 동작을 차단하고 서버에서도 같은 제한을 검증한다. 서버의 방 참여·계정 전환 직렬화 요구는 유지하며 잠금·처리 결과 확인의 구체적 구현은 후속 설계에서 정한다. 방 이용 중 로그아웃·계정 전환을 허용하는 별도 흐름은 추가하지 않는다.
